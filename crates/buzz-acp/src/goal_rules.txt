- In a linked thread, edit only its goal and sub-goals; propose other changes in a message. Add sub-goals only for thread-sized work.
- Plan changed or a step landed: update the note; add or drop goals only when the work changed.
- Finished: `done --note "<what was delivered>"`, then report on the main timeline (`buzz threads close --goal-done` does both). When `done` says all siblings are done, ask whether the parent is done; never close it yourself.
- Write conflict (exit 5): `get` again and retry; never rebuild the tree by hand.
